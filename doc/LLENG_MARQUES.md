## Funcionalitats JavaScript

El sistema inclou les següents funcions de validació i filtrat:

- **Filtres d'incidències:** Permet filtrar per estat (actives/tancades) i assignació (assignades/no assignades)
- **Validació de formularis:** Controla que les dades siguin correctes abans d'enviar
  - Creació d'incidències: departament, tipus i descripció (mínim 20 caràcters)
  - Actuacions: temps, data i descripció (mínim 20 caràcters)
  - Edició: evita enviar formularis buits
- **Confirmacions:** Demana confirmació abans de finalitzar incidències
